# 速度と所要時間の仕様

到達圏・経路探索の重み（所要時間）を、リンクごとにどう決めるか。速度の決め方は 3 通りあり、探索グラフをそれぞれ別に組み立てる。

## 共通

- 所要時間（分）= リンクの長さ ÷ 速度。長さは頂点間の測地線（haversine、地球半径 6,371,008.8 m）の合計
- 順方向・逆方向の 2 つの重みを持つ。通れない向きは重みを持たない（一方通行）。通れる向きは 3 通りで同じ
- 長さ 0 のリンクも辺として残すため、重みは 1e-6 分を下限にする
- 渋滞・信号・交差点・右左折での減速や待ちは入れない。どの速度も「その速度で止まらずに走り続けた場合」

## 3 通りの速度

| 速度 | 名前 | 制限速度があるリンク | 制限速度が無いリンク | 探索グラフ |
|---|---|---|---|---|
| `posted` | 制限速度を使う（既定） | 制限速度 | class の既定値 | `network/<case>/graph/` |
| `legal` | 無い区間は法定速度 | 制限速度 | 国（州）の法定速度。引けなければ class の既定値 | `network/<case>/graph_legal/` |
| `class` | 道路の種類ごとの同じ速度 | class の既定値 | class の既定値 | `network/<case>/graph_class/` |

使い分け:

- `posted`: Overture のデータをそのまま使った結果。制限速度の入り方が国でまちまちなので（北京は 0〜4%、ロサンゼルスの motorway は 94%）、都市どうしの比較には向かない
- `legal`: 制限速度の抜けを法律の値で埋め、国ごとのデータの埋まり具合の差を減らしたもの。都市どうしを比べるときの基本
- `class`: 全都市で同じ物差しにした「道路網の形」の比較。現実の所要時間ではない（高速道路も 80 km/h）

選び方: API は環境変数 `ROUTE_SPEED`（既定 `posted`）、`scripts/10_build_graph_arrays.py` と `scripts/12_bench.py` は `--speed`。
API の `/health` の `speed` で、読み込んでいる速度が分かる。

## 制限速度（`scripts/09_build_network.py`）

Overture の segment の `speed_limits` から 1 つだけ取る。

- 条件の無いもの（`when` も `between` も無い）のうち、`max_speed` がある最初の 1 つ
- 単位が mph なら × 1.609344 で km/h に直す
- 0 以下・無いものは「制限速度なし」（`speed_posted = false`）
- segment を connector で切ったリンクは、元の segment の制限速度をそのまま持つ
- 時間帯・車種・区間（`between`）つきの制限速度、`min_speed` は使わない

全球の幹線では 31.2% のリンクに制限速度がある（motorway 64.9%・tertiary 23.2%）。

## class の既定値

`api/graph.py` の `SPEED_KMH`・`SPEED_LINK_KMH`（09 もここから読む）。

| class | 本線 km/h | ランプ（`subclass = link`）km/h |
|---|---|---|
| motorway | 80 | 45 |
| trunk | 50 | 30 |
| primary | 40 | 30 |
| secondary | 35 | 25 |
| tertiary | 30 | 20 |

日本の国土数値情報版（`../ksj-route-search-api`）の表（高速 80・国道 35・都道府県道 30・市区町村道 20）に近い値にした。
日本で `class` の東京→大阪は 378 分で、KSJ 版の 380 分とほぼ同じ。

## 法定速度（`scripts/14_legal_speeds.py`）

制限速度が無いリンクに、そのリンクのある国（州）の法律の既定の制限速度を当てる。結果は `network/<case>/legal_speeds.parquet`（link_id の順。country・key・urban・legal_type・legal_kmh）。

### 表

[osm-legal-default-speeds](https://github.com/westnordost/osm-legal-default-speeds) の `legal_default_speeds.json`（元は OSM wiki「Default speed limits」、CC BY-SA 2.0）。`data/legal_speeds/` に置く。242 の国・州。

### どの国（州）か

- リンクの始点のノードの位置を、Overture の divisions（`division_area`）の範囲に入れる。国は `subtype = country`、領海を含む `class = maritime` を優先（海の上の橋を落とさない）
- 州で法定速度が違う国（表に `US-CA` のような行がある国: US・CA・AU・BE・GB・NL・BS・FM）は `subtype = region` の範囲も使う
- 表は州 → 国の順に探す（`US-CA` が無ければ `US`）
- 範囲は 0.001° で単純化し、1° 四方に切ってから点を入れる
- どの範囲にも入らないノードは 0.32%

### 市街地か郊外か

法定速度は市街地か郊外かで違う国が多いが、Overture の道路にはその情報が無いので、幹線の密度で推定する。

- リンクの始点を 1 km 四方のマスに入れ、周り 3×3 マスの幹線の延長 ÷ 9 km² が 3 km/km² 以上なら市街地
- 都市の中心は 5〜16 km/km²（東京都心 16.1・ロンドン 8.3・北京 7.8・デリー 7.2・パリ 5.6・八王子 5.2）、郊外は 0〜2.8 km/km²（北京の 90 km 南 2.8・パリの 70 km 南 1.3）
- 全球のリンクの 28% が市街地
- motorway（ランプを含む）は市街地でも郊外として引く（米国の州などの表に motorway の行が無く、市街地の 25 mph が当たってしまうため）
- 幹線だけの密度なので粗い推定。しきい値は `--urban` で変えられる。`--probe` で地点ごとの密度を見られる

### 道路の種類の選び方

ライブラリ（`LegalDefaultSpeeds.getSpeedLimits`）と同じ規則で、表の国（州）の行から 1 つ選ぶ。

1. 名前の無い行（既定）より下の行を下から、上の行を上から見て、最初にフィルタが当てはまる行。まずタグの完全一致の `filter` だけ、次に `fuzzyFilter` も使う
2. どれにも当たらなければ名前の無い行
3. 行の `maxspeed` を km/h に直す（`mph` は × 1.609344、`walk` は 6）。`none`（ドイツのアウトバーンなど）は `maxspeed:advisory`（推奨速度）

フィルタは OSM のタグを見るので、Overture から次のタグを作る。車線数・中央分離帯は Overture にほぼ無いので仮定を置く。

| タグ | 値 | 条件 |
|---|---|---|
| `highway` | class（ランプは `<class>_link`） | すべて |
| `oneway` | `yes` | 一方通行 |
| `dual_carriageway` | `yes` | 一方通行の本線で、motorway・trunk か郊外のもの |
| `dual_carriageway` | `no` | 上以外の一方通行（市街地の一方通行の街路）。表の `fuzzyFilter` が一方通行を中央分離帯ありとみなすのを打ち消す |
| `lanes` | `2` | 一方通行の motorway・trunk の本線（片側 2 車線とみなす。lanes が無いと表では「片側 1 車線」になる） |

`{urban}`・`{rural}` は上の市街地の推定で置き換える。ほかのフィルタ（歩道・照明・沿道など）に使うタグは作らないので当たらない。

主な結果（km/h）:

| 国 | 市街地 | 郊外 | 中央分離帯のある幹線 | 高速道路 |
|---|---|---|---|---|
| 日本 | 60 | 60 | 60 | 100 |
| 中国 | 50 | 70 | 70 | 120 |
| インド | 70 | 70 | 100（片側 2 車線） | 120 |
| フランス | 50 | 80 | 110 | 130 |
| ドイツ | 50 | 100 | 130（推奨。片側 2 車線） | 130（推奨） |
| 英国 | 48（30 mph） | 97（60 mph） | 113（70 mph） | 113（70 mph） |
| ブラジル | 60 | 100 | 110 | 110 |
| 米国カリフォルニア | 40（25 mph） | 105（65 mph、片側 1 車線） | 89（55 mph） | 89（55 mph） |

### 埋まり具合

- 制限速度の無いリンク（68.8%）のうち 93.5% が法定速度で埋まる
- 表に無い国は class の既定値のまま。延長の多い順にイラン・アルジェリア・エチオピア・イラク・マレーシア・シリア・モロッコ・マリ・バングラデシュ・北朝鮮など

## 気をつけること

- どの速度も上限の速さで走り続ける計算で、実態より速い。特に市街地は、信号・交差点・渋滞で実際の平均速度が制限速度の半分以下になることも多い。`legal` で市街地も 70 km/h のデリーなどは、とくに速く出る
- 実態に近づけるには、実際の所要時間（外部の経路探索など）と照らし合わせ、class と市街地・郊外ごとに割引の係数を決める（issue #4 の次の段階）
- 右左折の時間を入れるには、交差点での曲がり方まで表すグラフにする必要がある
